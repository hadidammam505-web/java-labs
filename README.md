# Java Labs ☕

University Java lab exercises, built with **NetBeans** (Ant).

## Labs

| Lab | Topic |
|---|---|
| [`Lab1`](Lab1) | First program: `System.out.println` and escape sequences (`\n`, `\t`, `\\`, `\"`). |

## Run

Open a lab folder in NetBeans and press **Run**, or from the command line:

```bash
cd Lab1
ant run
```

Or without Ant:

```bash
javac -d out Lab1/src/lab1/Lab1.java
java -cp out lab1.Lab1
```

More labs will be added as the course goes on.
